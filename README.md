💼 e-Tendering Portal
The e-Tendering Portal is a full-stack web application developed using Django, Python, SQLite, HTML/CSS, and Bootstrap to digitize and streamline the tendering process. This system allows buyers to float tenders and sellers to submit competitive bids in a transparent and secure manner, ensuring fair selection and efficiency. Key features include role-based authentication, tender lifecycle management, automated email notifications, encryption-backed password handling, and a clean, responsive UI. The project enhances transparency, reduces paperwork, and minimizes manual inefficiencies—offering an eco-friendly and scalable solution to traditional procurement systems.

🔐 Roles: Buyer, Seller, Admin
⚙️ Key Features: Tender creation, bid submission, auto-award logic, secure login, password reset
🛠️ Tech Stack: Django | Python | SQLite | Bootstrap | HTML/CSS
